# ProjetApp

Application web développée avec ASP.NET Core MVC (C#) et Entity Framework Core.

## Fonctionnalités

- Authentification et gestion des utilisateurs
- Gestion des données via une base de données
- Interface web basée sur le modèle MVC

## Technologies

- C# / .NET
- ASP.NET Core MVC
- Entity Framework Core
- HTML / CSS / JavaScript
- Visual Studio

## Structure du projet

```
projet.net/
├── DS_G4.slnx            Solution Visual Studio
└── ProjetApp/
    ├── Controllers/      Logique des pages
    ├── Models/           Modèles de données
    ├── Views/            Pages Razor
    ├── Migrations/       Migrations de la base de données
    ├── wwwroot/          Fichiers statiques (CSS, JS, images)
    ├── Program.cs        Point d'entrée
    └── appsettings.json  Configuration
```

## Installation

1. Cloner le dépôt :

```
git clone https://github.com/yahiachakchouk5-sudo/projet.net.git
```

2. Ouvrir `DS_G4.slnx` avec Visual Studio.
3. Configurer la chaîne de connexion à la base de données dans `ProjetApp/appsettings.json`.
4. Créer la base de données avec la commande `Update-Database` (Console du Gestionnaire de package).
5. Lancer l'application avec F5.
